# ChessZero v1.1.0 — Runtime Threads/Hash Matrix

This phase hardens the Android/Chessis runtime configuration path for the
full device-facing range used in testing:

- Threads: 1, 2, 3, 4, 5, 6, 7
- Hash: 16, 32, 64, 128, 256 MB

The Hash value is a **total budget for the configured search contexts**, not a
multiplier by thread count.

## What is tested

1. Every 7 × 5 = 35 Threads/Hash combination is configured and checked.
2. Threads is walked 1 → 7 while retaining each Hash profile.
3. Hash is walked 16 → 256 → 16 while retaining every thread count.
4. A depth-3 search is run at every thread count with 16 MB Hash.
5. The UCI test changes Threads and Hash while `go infinite` is active; each
   option change must stop the cancelled search, apply the new runtime pool,
   and avoid emitting a stale `bestmove`.
6. A mixed sequence alternates Threads and Hash changes while search is active.
